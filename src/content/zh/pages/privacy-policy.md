最后更新：2026 年 6 月 9 日

这是 Jiyu Yan 的个人网站，用于发布职业信息、项目、技术文章和精选随笔。

我尽量减少数据收集。本页说明访问 `yanjiyu.com`、联系我或使用评论等交互功能时，可能处理哪些信息。

## 本站可能处理的信息

### 你提供的信息

通过邮件、联系表单或链接的社交与职业主页联系我时，我可能收到你主动发送的信息，包括姓名、邮箱、消息内容，以及你附上的职业信息。

这些信息仅用于阅读、回复和管理对话。

### 技术信息

访问本站时，托管提供方及相关基础设施可能处理常规技术信息，包括 IP 地址、浏览器类型、设备信息、请求页面、来源页面和请求时间。

这些信息用于网站正常提供服务、安全、调试、防止滥用及保障可靠性。

### 评论

部分文章可能使用基于 GitHub Discussions 的 Giscus 评论。如果你选择评论，GitHub 可能依据其隐私条款处理你的 GitHub 账号信息、评论、回应及相关元数据。

阅读本站无需发表评论。

## Cookie 与本地存储

本站可能在浏览器中保存少量本地偏好，例如浅色或深色主题。这些信息存储在你的设备上，仅用于保持你选择的显示方式。

本站目前不使用广告 Cookie 或定向广告追踪。GitHub/Giscus 等第三方服务，以及你主动打开的外部链接，可能使用其自身的 Cookie 或存储。

## 分析统计

本站目前未启用 Google Tag Manager。如果未来加入分析功能，应更新本政策，说明收集内容及用途。

## 信息用途

信息用于：

- 提供与维护网站；
- 回复消息和职业咨询；
- 防止滥用或技术问题；
- 了解内容与页面是否正常工作；
- 支持可选的评论功能。

我不会出售个人信息。

## 信息分享

运行网站所需的服务可能处理信息，例如托管、邮件、GitHub/Giscus 评论、域名、部署和安全服务商。它们依据各自的条款和隐私政策处理信息。

法律要求、保护权利或安全、调查网站滥用时，我也可能披露信息。

## 保留期限

联系消息仅在通信、职业交流或记录保存仍有用途的期间保留。服务器日志和基础设施记录遵循相关提供方的正常保留期限。

评论按照 GitHub/Giscus 设置保持可见，除非由评论者、仓库维护者或 GitHub 删除。

## 你的选择

你可以：

- 不使用可选评论功能；
- 通过浏览器设置删除或阻止本地存储；
- 联系我，申请访问、更正或删除你直接发送给我的个人信息；
- 通过 GitHub 账号及其隐私控件管理 GitHub/Giscus 评论数据。

根据居住地，你还可能享有适用法律规定的其他隐私权利。

## 外部链接

本站链接到 GitHub、LinkedIn 及文章提及的其他第三方网站。我不对这些外部网站的隐私做法或内容负责。

## 儿童隐私

本站不面向儿童，也不会明知而收集儿童的个人信息。

## 变更

网站、托管、分析、评论或联系功能变化时，我可能更新本政策。顶部的“最后更新”日期表示最近一次修订时间。

## 联系

如有隐私问题或请求，请发送邮件至 [hi@yanjiyu.com](mailto:hi@yanjiyu.com)。
